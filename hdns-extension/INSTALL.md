# HDNS Browser Extension v2.0 — Citizen Installation Guide

## Quick Start

### Chrome / Edge / Brave

1. **Download** the `hdns-extension/` folder from:
   `https://github.com/HOPEAIHUB/tuk-publication-website/tree/main/hdns-extension`

2. **Open** your browser's extension page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`

3. **Enable Developer Mode** (toggle in top right corner)

4. **Click "Load unpacked"** and select the `hdns-extension/` folder

5. The HDNS extension is now active! You'll see the HDNS icon in your toolbar.

### Firefox

1. **Download** the `hdns-extension/` folder
2. **Open** `about:debugging#/runtime/this-firefox`
3. **Click** "Load Temporary Add-on"
4. **Select** the `manifest.json` file inside the folder
5. The HDNS extension is now active!

## Troubleshooting

### Extension not redirecting?
- Make sure the extension is enabled in `chrome://extensions/`
- Try refreshing the page after installing
- Check the extension popup for status

### Domain not found?
- The HDNS resolver API might be down — check the popup status
- Only sovereign TLDs are supported (see list above)
