HDNS Browser Extension

Install the HDNS browser extension to access sovereign TLDs directly in your browser address bar:

  • Type www.gov.tuk → resolves to TUK government portal
  • Type www.gov.core → resolves to TUK core government
  • Type www.tuk.core → resolves to TUK core
  • Type vision.tuk → resolves to vision statement

Download the extension from the GitHub repository: /hdns-extension/ folder. Load as unpacked extension in Chrome/Edge/Firefox.
