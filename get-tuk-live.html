What HDNS Does

HDNS (Hope DNS) is a browser extension that lets you type sovereign domain names like www.gov.tuk, vision.tuk, or www.hope directly into your address bar — and they resolve to the live TUK government website.

It works because .tuk is not registered with ICANN (the old world's domain system). Instead, HDNS intercepts requests for 15 sovereign TLDs and redirects them to the live TUK site hosted on HOPE AI infrastructure. No ICANN fees. No third-party money-based dependencies. Zero corruption.

Install in 3 Steps

1️⃣

Download the Extension

Download the HDNS extension files from our GitHub repository:

📦 View on GitHub

Or clone: git clone https://github.com/HOPEAIHUB/tuk-publication-website.git
The extension is in the hdns-extension/ folder.

2️⃣

Load in Your Browser

Chrome / Edge / Brave:

  1. Open chrome://extensions/
  2. Enable "Developer mode" (top right toggle)
  3. Click "Load unpacked"
  4. Select the hdns-extension/ folder

Firefox:

  1. Open about:debugging
  2. Click "Load Temporary Add-on"
  3. Select manifest.json
3️⃣

Type a Sovereign Domain

Now try typing any of these in your address bar:

www.gov.tuk vision.tuk about.tuk bank.tuk www.hope www.core

✅ Each one redirects to the live TUK site!

Why Sovereign TLDs?

The old world's domain system (ICANN) charges $185,000+ per TLD and takes years to approve. It's a money-based gatekeeping system. TUK creates its own TLDs — .tuk, .core, .hope, and 12 more — because a sovereign nation shouldn't need permission or pay money to name itself.

HDNS is the bridge — it makes sovereign TLDs work in today's browsers while we work toward full ICANN recognition. Zero corruption. Zero money-based dependencies. LOLY Mandate enforced.
